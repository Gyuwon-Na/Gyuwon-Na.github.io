Research Project

ROI-Based Matching with HNSW

MM 2025 Feature Matching / Approximate Search
C++ Python OpenCV HNSW
ROI Matching Pipeline Placeholder

Research Question

Can feature matching be made faster and more robust by combining spatial region constraints with approximate nearest-neighbor search? This project explores how ROI filtering and HNSW indexing can reduce unnecessary descriptor comparisons while preserving match quality.

System Design

  • Extract feature descriptors from candidate frames and assign them to region-of-interest buckets.
  • Use ROI constraints to reduce the search space before performing descriptor-level nearest-neighbor lookup.
  • Apply HNSW indexing to accelerate similarity search where the descriptor pool remains large.
  • Validate matches with geometric consistency checks to reject plausible but spatially invalid correspondences.

Why It Matters

Matching quality directly affects localization, mapping, tracking, and image registration systems. A practical portfolio version of this work should show the trade-off curve between speed, recall, and false matches rather than presenting a single best-case demo.

Evaluation Plan

Speed

Compare brute-force, ROI-only, HNSW-only, and ROI+HNSW matching time.

Recall

Measure how many valid correspondences survive each filtering stage.

Precision

Track false matches after geometric verification.

Future Work

  • Integrate a reproducible benchmark with public image sequences and fixed parameter sweeps.
  • Explore adaptive ROI sizing based on camera motion and expected object scale.
  • Package the matching pipeline as a reusable module with clear profiling hooks.
