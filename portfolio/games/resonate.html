Resonate

Sep 2023 - Dec 2023 GAM 100 Project
C++ Raylib 2D Gameplay Team Project
Gameplay Capture Placeholder

Overview

Resonate is an early team game project that helped establish my foundation in C++ gameplay programming. The project emphasized shipping a complete experience with a constrained toolset: core loop, interaction rules, UI flow, audio/visual feedback, and predictable behavior across repeated playthroughs.

What the Detail Page Shows

  • How I decomposed gameplay into small systems that could be tested and adjusted independently.
  • How player feedback was tied to state changes so mechanics felt understandable rather than hidden.
  • How the team balanced scope with reliability to complete the project on schedule.

Technical Highlights

Input & Control

Implemented responsive player input with clear separation between input capture and gameplay response.

State Flow

Managed transitions between active play, win/loss conditions, and reset behavior.

Game Feel

Connected mechanics to visual and audio feedback to make actions legible to the player.

Challenges & Solutions

1 Building a Complete Loop
Challenge

The project needed to feel complete even though the team was still building fundamental programming and collaboration habits.

Solution

Kept the scope tight, implemented the core loop first, and used each milestone to harden existing behavior before adding new content.

Reflection

Resonate was the project where I began thinking like a systems programmer. It taught me that even a small game benefits from clean ownership, clear update order, and fast feedback during testing.
