Fog

APR 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The Fog project was a part of the Computer Graphics course. The goals of this project were twofold:

First, to implement various fog rendering techniques in shaders. Second, to integrate them into an interactive graphics demo.

Tasks Completed

  • Vertex Transformations: Modify all vertex shaders to ensure they correctly convert model vertex positions into clip space.
  • Fog Techniques: Implemented various fog techniques (linear, exponential, and fragcoord_z) in fragment shaders.

Reflection & Future Work

  • I felt it somewhat counterintuitive and unnatural that in linear fog, when the fog near value is greater than the fog far value, objects closer to the camera become invisible while those farther away remain visible.
  • Although I did not encounter any major issues or errors during this project, this observation significantly deepened my understanding of calculation differences between various fog techniques.
