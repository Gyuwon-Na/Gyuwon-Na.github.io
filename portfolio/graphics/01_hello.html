Cross-Platform Foundations: Hello Quad

SEPT 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The Hello Quad project was a part of the Computer Graphics course. The goals of this project were twofold:

First, to implement and set up the foundational rendering features using OpenGL. Second, to build and run the application seamlessly across both Windows and Web platforms by displaying a simple, dynamically animated quad.

Tasks Completed

  • API Abstraction: Implemented C++ classes to robustly encapsulate low-level OpenGL API objects, including Textures, VertexBuffers, IndexBuffers, and VertexArrays.
  • Shader Programming: Created custom vertex and fragment shaders (GLSL) to appropriately render and style the quad onto the screen.
  • Input Handling: Updated the application's demo logic to feed interactive animations based on elapsed time, mouse position, and mouse wheel delta.
  • Custom Animation: Designed dynamic, time-based animations directly within the shader code to visually manipulate the quad in real-time.

Reflection

1 Texture Binding & Buffer Order Operations
Challenge

I struggled significantly with displaying textures on the window. Although I wrote code logically similar to what was implemented with OpenGL in previous semesters, the texture simply failed to appear on the screen.

Solution & Takeaway

Through debugging, it turned out that the core issue stemmed from the incorrect ordering of buffer binding and std::move operations in C++. From this experience, I learned exactly how critical the correct order of operations is when working within the strict state-machine constraints of OpenGL binding buffers.
