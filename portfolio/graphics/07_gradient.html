Gradient Noise

JUN 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The Gradient Noise project was a part of the Computer Graphics course. The goals of this project were twofold:

First, to extend the graphics framework to support new texture formats. Second, to implement a 3D Gradient Noise algorithm using a 2D texture lookup approach.

Tasks Completed

  • Noise Functions: Implemented a value noise-based noise function using GLSL.
  • Procedural Patterns: Developed various procedural noise patterns such as fractal sum, turbulence, marble, and wood.
  • 3D Noise Construction: Understood and applied the method of generating 3D noise using gradient vectors and a permutation table.

Challenges & Solutions

1Gradient Vectors & Layout Mapping
Challenge

There was an issue related to layout location, similar to what happened with value noise. I also mistakenly thought that the number used with the modulo operator (%) had to exactly match the number of gradient direction vectors.

Reflection

Through this assignment, I was able to gain a deeper understanding of how a noise function is constructed, especially how the permutation table and gradient vectors are connected to generate continuous noise.
