Shadow Mapping

SEPT 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The Shadow Mapping project was a part of the Computer Graphics course. The goals of this project were twofold:

First, to implement robust shadow mapping techniques. Second, to integrate them effectively into an interactive graphics demo.

Tasks Completed

  • Perspective Light Source: Implement shadow mapping for a light source modeled as a perspective camera.
  • Texture Enhancements: Modify the Texture class to support depth and RGBA8 color textures.
  • Framebuffer Management: Implement and use the FrameBuffer class for rendering depth maps.
  • Matrix Operations: Utilize a Camera class to generate proper view and transformation matrices.
  • Visualization & Integration: Visualize shadow maps and the light frustum, and integrate shadow mapping techniques into an interactive demo.

Reflection

1Linear vs Gamma Space Lighting
Challenge

When I first noticed that the scene looked too dark, I thought it was simply due to incorrect lighting calculations or improperly passing matrices.

Solution & Takeaway

I learned a new concept called gamma correction. I realized that the actual cause was the difference between gamma space and linear space. Understanding this distinction helped me fix the lighting issues and create more realistic rendering results.
