CS250 Final Project

MM 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The CS250 Final Project combines the course's rendering topics into one cohesive interactive scene.

I built an OpenGL beach scene that brings together procedural geometry, noise-based terrain, shader-controlled lighting, and real-time interaction so the final demo feels like a small graphics sandbox rather than a set of isolated assignments.

Tasks Completed

  • Interactive Objects: Rendered a beach ball using procedural geometric modeling; this ball can rotate and move according to mouse position and arrow keys.
  • Dynamic Lighting: Configured lighting to change the beach color smoothly from day to night.
  • Environment Rendering: Modified Perlin noise to create the sandy beach and implemented light reflections along the shoreline.

Reflection

1Shader Uniform State Management
Challenge

I encountered cases where sending uniforms to a different shader after calling use() caused issues. I also didn't fully understand how noise scale works initially.

Solution & Takeaway

I realized I need to use a shader before sending uniforms to it; otherwise, the uniforms won't be set correctly. For the noise scale, I continuously adjusted the shader values to get a similar visual result and gradually achieved the intended look.
