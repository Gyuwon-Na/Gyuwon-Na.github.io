Toon Shading

SEPT 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The Toon Shading project was a part of the Computer Graphics course. The goals of this project were twofold:

First, to implement different toon shading techniques and work with normal transformations using a Normal Matrix. Second, to implement Linear Fog within a toon shading pipeline and integrate these shading techniques into an interactive demo.

Tasks Completed

  • Custom Ranges: Applied Custom Ranges Toon Shading to allow viewers to define their own lighting thresholds and shading styles.
  • Uniform Ranges: Used Uniform Ranges Toon Shading for evenly spaced shading steps, allowing adjustable levels without manual tuning.
  • Gradient Control: Used a 1D gradient texture to control diffuse shading levels, allowing for artistic flexibility in light response.
  • Visual Enhancements: Smoothed specular highlights with thresholding and implemented linear fog styles.
  • Performance Testing: Handled both anti-aliased and non-anti-aliased rendering modes for comparison and performance testing.

Reflection

1Specular Highlights Distribution
Challenge

Initially, I used the view vector V by normalizing vPosition and computed the half-vector H as L + V for the specular component. However, this caused the shape of the light source to appear too clearly on the surface, which was not the intended effect.

Solution & Takeaway

Replacing the eye vector with a constant (0, 0, 1) and computing H as L + Eye helped distribute the specular highlights more evenly across the surface, achieving the desired visual outcome.
