Procedural Geometric Modeling

SEPT 2025 CS250 Coursework
C++ OpenGL GLSL WebGL CMake

Interactive Demo

Overview

The Procedural Meshes project was a part of the Computer Graphics course. The goals of this project were twofold:

First, to implement procedural mesh generation algorithms. Second, to integrate the generated meshes into an interactive graphics demo.

Tasks Completed

  • Rendering Implementation: Implemented functions to render plane, cube, cylinder, sphere, cone, and torus.
  • Index Architecture: Constructed the index buffer for mesh connectivity.
  • Procedural Generation: Generated vertices for a procedurally created plane.

Reflection

1 Data Type Distortions
Challenge

There were cases where the shape was not drawn correctly or appeared distorted when the current row and column were defined as integers.

Solution & Takeaway

After casting into float, the cylinder and cone rendered correctly. I learned that converting integers to floats ensured smooth and accurate shape generation in calculations.

2 Texture Application and Vertex Attributes
Challenge

Additionally, although the wireframe was rendered correctly, the texture was not applied properly. I attempted to fix the issue by modifying the fragment shader, but only the plane and the front side of the cube rendered correctly, matching the demo example.

Solution & Takeaway

After further investigation, I realized the issue was related to vertex attribute pointer setup. The problem was resolved by correctly calculating the buffer starting point. Additionally, properly aligning vertex attributes and handling offsets correctly is crucial for accurate texture mapping and rendering.
